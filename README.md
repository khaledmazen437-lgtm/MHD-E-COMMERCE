# MHD Shop - Fashion E-Commerce Website 🛍️

A modern, fully responsive e-commerce front-end website for men's fashion. This project simulates a complete shopping experience including product browsing, detailed product views, and a dynamic shopping cart system.

🔗 **Live Demo:** [Click here to visit the website](https://khaledmazen437-lgtm.github.io/MHD-E-COMMERCE/)



## ✨ Features

- **📱 Fully Responsive:** Optimized for Mobile, Tablet, and Desktop devices.
- **🛒 Dynamic Shopping Cart:**
  - Add items to the cart.
  - Update quantities (increase/decrease).
  - Remove items.
  - Automatic total price calculation.
- **🖼️ Interactive Product Page:**
  - Image Gallery with thumbnail selection.
  - Size & Color selection logic.
- **✨ UI/UX Enhancements:**
  - Auto-playing Testimonials Slider.
  - Modern layout using CSS Grid & Flexbox.
  - Clean Navigation Bar with Mobile Menu support.

## 🛠️ Technologies Used

- **HTML5**
- **CSS3** (Flexbox, Grid, Media Queries)
- **JavaScript** (DOM Manipulation)
- **FontAwesome** (Icons)
